# Statement of the Problem

This essay states what the observer-space program is trying to do, and why Bell's theorem does not rule it out. It is David Strayhorn's own statement: strong opinions, strongly held. It guides how the program answers reviewers.

**Current version:** [`versions/v0.1.md`](versions/v0.1.md), awaiting David's sign-off.

## Change control

1. **Sign-off.** The essay changes only with David's explicit sign-off. No agent or reviewer edits it on their own.
2. **Log.** Every change gets a changelog entry in the new version. The entry names the challenge that forced the change: the review, objection or result, with a link.
3. **Precedence.** This essay takes precedence over *Mathematical Foundations* (`public-essays/mathematical-foundations/`) and over the papers. Where they conflict, the conflict is raised with David. The essay is not quietly overridden.
4. **Length.** The essay stays very short. The notes and the deferred list may change as *Mathematical Foundations* develops, but only under rules 1 and 2.
