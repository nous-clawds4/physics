This essay will remain simple, sticking with the language of layers or stages rather than nodes. We develop this one node at a time. Additional nodes will be developed, and existing nodes updated as needed, until this goal is reached. Consider each node to be a strong opinion, strongly held at the top, but slighly less strongly held with each new node. The top node is a strong opinion, strongly held. Each child node is equally strong, in the sense that we are running with it; but more weakly held than its parent; or at least never held more strongly than its parent(s). Paths not taken will exist as child nodes and will contain the thought process for rejecting it; maintaining the node may be useful to resurrect a previously discarded idea later, but more importantly, will bolster the rationale for taking the path we are taking. Any given paper will map to a series of paths starting from the base node, traversing all accepted nodes, not traversing rejected nodes. Decision making points between alternatives will be labelled as such; and may often be triggered by a succinct question, like the following: One decision-making fork we need to add in the graph: triggered by a question. Are there physical objects that can be on observer and objects that cannot? Privileged pieces of matter vs not privileged? We will discuss but reject the notion that being an observer requires some special quality. Reject on what grounds? Because there is no special quality. Just like there is no preferred frame of reference in GTR. A rejected child node for privileged pieces of conscious matter. Accepted node will be: no privileged pieces of matter. Justification: by analogy to all great scientific revolutions: our place in the world is not privileged; inability to accept that fact is what hinders progress. Maybe the graph needs to be defined in large measure by question-nodes. Selecting the right questions is the heart of the matter. Proposed name for this IH method: the Path of 42. 42 is in reference to HHGTTG, stressing that the hard part is not answering the question, but asking it. Path is in reference to our method, which is selecting the path through the graph. Many questions will be of the a priori (not a posteriori) category: we are defining our terms, and hopefully selecting the most useful terminology. So many question nodes will be: what is the definition of (some term that we used in a higher up node)? Note the implication: we can use terms even before we have defined them in full. Because maybe there's no such thing as a completed definition. It's always being expanded. This is the epistemology of the concept graph. Posing the next question is under appreciated step. Often the question is: how to define something. Only rarely do we inject physical hypotheses, which is to associate some variable with an experimental finding. In our case, it will be to associated a variable with the relative probabilities of a particle arriving at one of several detectors.

Consider whether this should be envisioned as layers, one on top of another, or as a graph, with nodes, building on nodes before it. Each node represents a choice among competing alternatives: which mathematical tools to use, which avenue to explore, where to introduce a physical postulate, which definition of a term that was introduced at a higher node.
