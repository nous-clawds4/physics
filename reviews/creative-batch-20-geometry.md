## Geometry checks
1. **Convention.** Cover lift of the hit: X = x + nL, x in [0,L) = arc length along the oriented screen from the foot point (0,D). So X − x = nL, n = floor(X/L); n ∈ Z, negative for θ < 0. The note's L_n = (X−x)/n is consistent with this sign. D is transverse to the identification and unaffected by the quotient.
2. **What L_n assumes.** The launch (hence X) is known, x is known as a point of [0,L) measured from the foot point with a chosen orientation, and the deck group is generated by one translation of unknown length L. X − x is a cover quantity; it is well-defined here only because X is fixed by the launch, not read from the world.
3. **n = 0.** x = X: no division; every L > max(X, 2ρ) fits, a continuum. The record class is not always discrete. The script notes this ("n=0 needs x=X"), the prose drops it.
4. **Finiteness.** L_n > x gives n < (X−x)/x, so the list is finite for x > 0 (here n = 1, 2: L = 5.0, 2.5). It is an infinite harmonic sequence accumulating at 0 only when x = 0, cut by the tube L > 2ρ.
5. **Reference and invariance.** The source sits on the cut, and "the straight segment in [0,L)" is a rule-defined, different segment in each W_L. Absolute n shifts with the cut; only differences n − n' between routes to the same endpoint are cut- and basepoint-free (#381, #387). Fine as a declared-reference label, but must be said.
6. **Per world vs per route.** In W_L with a given screen point x, there is one geodesic per n, with launch θ_n = arctan((x+nL)/D) (e.g. hit 2.0021 in W_2.5: θ = 11.32°, 24.24°, 35.00°, 43.54° for n = 0..3). So n is per route. It is fixed per world only because the launch is part of the world (#399 R2). The two-slit analogue (two routes to one point in one world) is two launches, whereas Set 2 is one launch across many worlds. Both are fine, but the note must not identify them.
7. **Sawtooth.** x(L) = X − nL is piecewise linear with slope −n on (X/(n+1), X/n], jumping at L = X/n, teeth crowding toward L → 0. It is a periodic sawtooth only in X at fixed L.
8. **Timing.** With θ fixed, the arrival time is L-independent (correct). Across routes to a fixed point (different θ_n) the times differ, so timing would separate routes, not worlds.
9. **L78.** Correct: classical point hits plus no measure give no fringes. A per-route count is the labelled counting conjecture; (M1) is unchanged. Choosing a weighting because it produces fringes is a T2 risk. Even then it weights a finite set of points with no phase, so it gives no bands.
10. **Well-posedness principle.** "Which route" is ill-posed on the record unless n is constant on the record class, and "which n" in absolute terms is ill-posed without the declared reference. Both statements are correct and should be kept.
