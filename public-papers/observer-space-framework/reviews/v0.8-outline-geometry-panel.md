## 1. F4 and F5 (Item 4)

**F4. Index: keep $E_W(O)$. Indexing by $O^u$ gives the same set, so "both" is harmless.**
- *Membership.* An occurrence of the lump $O$ at $p$ is a pointed analytic diffeomorphism $\varphi$ from a presentation to $(M,p)$. It carries each $u$ to $\varphi_*u$, so $(M,p,\varphi_*u)$ is an occurrence of $O^u$. As sets of pointed worlds, then, $E_W(O)=E_W(O^u)$. That matches §2's rule that $\mathrm{Obs}$, lumps without $u$, is used where orientation plays no role.
- *§5.1 continuum theorem (C24, C25).* $u$ enters only as *which geodesic ends*: "the observer's geodesic" is $\gamma_{O^u}$, which the text already names. The count does not need $u$. An isometry of Minkowski space minus a point $q$ extends to a Poincaré map that fixes $q$, so it preserves the interval from $p$ to $q$. Distinct $\tau_0$ therefore give distinct pointed worlds, and $E_W(O)$ is at least a continuum without $u$. C25 works the same way, with the axis distance as the invariant, as stated there.
- *EPP2.* An arm is oriented, but its ensemble depends on the arm-to-ensemble map. Under F6 that map is explicitly not fixed, so EPP2 does not settle the index.
- *What changes:* no claim and no pin. E2, E4, E5, C24 and C25 are unchanged. Bare $E_W$ (E3–E5, E7) reads as $E_W(O)$.
- *Optional disclosure* (§2, right after Item 4's proposed definition sentence), if the Lead wants I1 closed in the text:
```text
Indexing by $O^u$ gives the same pointed worlds, since each occurrence of the lump carries an occurrence of $O^u$; orientation enters only through the observer's curvelet $\gamma_{O^u}$, as in §5.1.
```

**F5. Multiplicity: keep "collection" and add a disclosure.**
- §5.1 uses only $E_W$. EPP2 offers $|E_W|$ *or* $|E_M|$ as two sizes.
- If $E_M(O)$ is the multiset obtained by forgetting $p$ (v0.3's reading: the same $M$ appears once per distinct anchor), then $|E_M|=|E_W|$. That holds for the cardinality and for any exhaustion pushed forward, so EPP2's two sizes coincide. The "or" is idle; it was already idle in v0.3's EPP2a/EPP2b.
- Counting each manifold once gives a genuinely different size. §5.1's own C24 family shows this: a continuum of members of $E_W(O)$, but a single manifold up to isometry, because translations carry Minkowski minus $q$ to Minkowski minus $q'$.
- So choosing "multiset" would change EPP2's content (a foil, but still content). Following the ruling, the wording stays and a disclosure is added. It combines with the F6 disclosure, which also needs an antecedent: v0.7.1's EPP2 no longer contains v0.3's "once an arm-to-ensemble map is defined", so "such map" would dangle.

OLD (v0.7.1 §7; exactly once):
```text
EPP2 weights an arm in proportion to its post-branch ensemble size, $|E_W|$ or $|E_M|$.
```
NEW (I5's cross-reference, then F6 with the Lead's string verbatim, then F5):
```text
EPP2 weights an arm in proportion to its post-branch ensemble size, $|E_W|$ or $|E_M|$ (§2; see the product ansatz below). An arm's post-branch ensemble needs an arm-to-ensemble map. No such map is fixed here. Nor is it fixed whether $E_M$ counts a manifold once or with multiplicity; with multiplicity, $|E_M|=|E_W|$ and the two sizes coincide.
```
