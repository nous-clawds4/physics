## Nits (optional; not HOLD)

1. **R-c, Wald's identity (Geometry's call).** The identity needs a stopping time with finite expectation, or a truncation. At $c=0.01$ the text says "the orbit random-walks away", so finiteness is not shown. Suggested text: "($E[\text{jumps}]=\tfrac23E[\text{decisions}]$ by Wald's identity, for histories stopped at any fixed number of decisions, since $m=2$ at every bound decision)". The optional reference is above.
2. **R-b (Geometry's call).** "At every decision $m\le1$ … so each decision is a fair coin" reads oddly if $m=0$ counts as a decision. If "decision" means a branch point, the sentence is fine. Otherwise: "At every turning point $m\le1$ (one outgoing edge at most), so each decision is a fair coin between continuing and the one jump".
3. **§11.** "This file is the current draft, pending the panel check. This file expands [`v0.7-outline.md`]" could read "It patches v0.7-prose, which expands [`v0.7-outline.md`]", to match the Status paragraph.
