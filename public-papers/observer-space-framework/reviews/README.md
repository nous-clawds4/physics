# Reviews

Each review is a markdown file in this folder.

## Naming

`vX.Y-<label>-<reviewer>.md`

Examples:

- `v0.1-outline-literature.md`
- `v0.1-outline-ontology.md`
- `v0.2-draft-external-alice.md`

## Required header

First lines of every review:

```markdown
# Review of v0.1-outline
Reviewer: <name or agent>
Date: YYYY-MM-DD
Verdict: HOLD | HOLE | NITS | COMMENT
```

State clearly which **version file** under `versions/` you read.

## Style

HOLD / HOLE / occupied / nits is welcome (same spirit as in-house kill-passes). Separate:

- **Postulate** (chosen launching pad)
- **Hope** (Born, Einstein, EPP1⇔EPP2)
- **Open** (tangent space, exhaustion, discrete \(B(O)\))
- **Firewall** (what the paper must not claim)

Do not demand a Born derivation from v0.1.
