## Ontology hygiene notes

1. **Fixed in #130 before filing: the C6 arm count under (a).** The r2 re-pin put C6 on $X'$ ($r=9.8926$) because the jump into $X'$ is (a)-admissible. But the "3 arms by segment" count used the rule as stated, and at $X'$'s own periastron the rule's *outward* edge fails (a), by the same $F(O)$ argument as C30. The pin now says "3 under the rule as stated; 2 if (a) is imposed". Arrival dependence (1 vs $\ge2$) survives either way, so the claim stands.
2. **Fixed in #130 before filing: two options were both called "(C)".** §4.2 uses "(C)" for target avoidance. #132 and the r1 §9 used "(C)" for returning to Paper 1's count. With MERW's Born hazard attached to the count option, the collision could misfile the hazard. §9 now uses (M1)/(M2), and the §4.2 label says "arrival option".
3. **$R\ne\emptyset$ is existential only.** Clause (ii) reconciles "Postulate asserted" with "EPP1 domain empty because no $R$ is adopted". Clause (iii) stops it being read as Paper 1's full non-uniqueness premise, which needs $\mathrm{succ}_R\ne\emptyset$ along given histories. Nothing downstream uses more than existence. It adds one abandonable hypothesis; that is the minimal filing.
4. **Paper 1 measure honesty.** The §10 row now rests on C12 alone ($1/6$ vs $1/2$ on co-existing evolutions), which is enough for "not carried". Uncountability is scoped to completed evolutions in the model without (a) (C16, a numerical witness, not a proof). Paper 1 §6's own "countable at a grain" escape is identified with (M2). That is fair to Paper 1: it is not declared refuted, only not carried under (M1).
5. **The co-existence reading is "adopted" while the measure is open.** This is consistent. The reading is the reading *of EPP1*, so it applies under (M1). If (M2) is chosen the reading must be revisited, and §9 lists that.
6. **The "Obs-local" definition is the author's choice.** Arm set and weights at $(O^u,a)$ depend only on that state and $R$. It coincides with the Markov locality of (A). It is not Bell's spacetime locality, and the Hope is phrased so that it claims nothing. Prose should keep the two localities visibly apart.
