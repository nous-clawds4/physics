### 1a. S1's vertices (computed)

- **FLRW.** $\nabla K=K'(t)\,dt$, which is parallel to $u$, so $\nabla K\in u^\perp$ forces $\nabla K=0$ at every $K$-vertex. $\hat n$ is undefined there. In C8's model ($H=2+\sin(1/(1-t))$) there are 64 such critical points on $[0,0.99]$, matching the paper. C8 uses $K$ for the slice $V^\tau$, not for the rule.
- **Schwarzschild bifurcation 2-sphere** ($U=V=0$, $r=2$). $dr=0$ there, so $\nabla K=0$. Every timelike geodesic through it has an isolated $K$ minimum there.
  - Under the throat convention, a target lands exactly on the sphere only by coincidence (measure zero).
  - No $[10,20]$ orbit point is such a vertex.
- **Kerr** ($a=0.9$, $\theta=\pi/6$, $M=1$).
  - $K=0$ at $r=2.908845727$, outside the ergosurface ($1.6265$) and the horizon ($1.4359$). $g_{tt}=-0.3585$, so a static observer exists.
  - Along that observer's geodesic, $d^2K/d\tau^2=-0.00294$, and $\nabla K=(0.0332,0.0557)\ne0$.
  - So this is an isolated vertex with $K=0$: $\varepsilon$ is undefined while $\hat n$ is defined.
- **What this implies.**
  - The rule as stated is not defined at every vertex.
  - The Firewall's "stated and uniform" and §5.4's "one rule … at every vertex" need S1's disclosure.
  - No instance figure depends on these vertices. S1's NEW states both facts.
