# Geometry quick verdict: creative batch 01 (#333) — do not merge

**Read at:** #333 head `fd3a904` (`creative/batch-01.md`, repo root; not under `notes/creative/`), main `2b215ec` plus #331 head `b374b58`. **Record type:** rough review; applies nothing; neutral on David's open calls. **Goal as stated in batch-01:** deterministic along stretches, a discrete number of branches fixed by the geometry (not chosen by us), no CTCs, branching of one traveller's *motion* (not only of universes), no measure smuggled.

**Ranking.** Set 1 (Sheets) > Set 3 (Loops in V) > Set 2 (Jet, not germ). Only Set 1 is flagged for a full note, and only for one narrow question (§1, last sentence).

## Set 1: Sheets

**Rigorous?** Yes. Precise definition: a host is an analytic Lorentzian manifold $M\setminus\Sigma$ that is locally an $n$-fold branched cover along a closed embedded codimension-2 submanifold $\Sigma$ (cone angle $2\pi n$); states are germs at $p\notin\Sigma$. Still undefined: $\Sigma$'s causal type, the field equations on $\Sigma$ (#332 R3: not a Geroch–Traschen distribution), and the germ at points of $\Sigma$. **Where it breaks.** Off $\Sigma$ the curvelet is unique (geodesic-lifts Prop 3.2/Thm 3), and one path has no monodromy, so "going around the seam" does not by itself give a choice: a traveller following one curve lands on whichever sheet that curve determines. Monodromy is a property of loops, i.e. of the host/ensemble ($E(O)$), not of motion. Branching of motion happens only on geodesics that *hit* $\Sigma$, and by dimension count a timelike curve in 4-d generically misses a 2-dimensional $\Sigma$ ($1+2<4$). So branches exist on a measure-zero set of curvelets unless something focuses orbits onto $\Sigma$, and the sheet rule after a hit is a law of $R$ in disguise. Inextendibility (#320) does not remove $\Sigma$: it can be imposed on $M\setminus\Sigma$, or $\Sigma$ adjoined as a singular set; which is chosen is new. **Gains.** The only set whose branch count is a topological integer fixed by the shape, with no CTCs; matches "discrete, not chosen" better than the others. **Full note:** yes, narrowly: whether any independently motivated mechanism (e.g. a hit set of positive measure, or codimension-1 seams) makes hits generic without a hand-picked sheet rule. If not, the set reduces to ensemble structure.

## Set 2: Jet, not germ

**Rigorous?** The state is definable (an $\infty$-jet at $p$ plus $u$), but "the traveller's next step" is ill-posed. In a non-quasianalytic class (Denjoy–Carleman; #331 §4, #332 R1, so already $C^\infty$, Gevrey adds nothing) the jet at $p$ fixes only the jet of the geodesic at $p$, not the geodesic on any interval $(0,\epsilon)$. **Where it breaks.** The non-uniqueness is not at points: every positive proper time already admits a continuum of continuations, because flat perturbations can switch on immediately. That is the "anything goes" end, everywhere, not discrete branch points. It also breaks the jet-germ-patch equivalence the record uses for $P(O)$ and for the uniqueness of the curvelet (Prop 3.2 assumes the germ), and the gauge quotient (#324) would need diffeomorphism jets rather than germs, where flat diffeomorphisms act trivially on jets, so the stratification by orbit type changes. **Gains.** Branching of motion, as the goal asks, but with no discreteness and with an obvious smuggling risk in any rule that picks a countable subset (batch-01 T4). Not flagged.

## Set 3: Loops in observer space

**Rigorous?** Not yet: "consistency around a return" is undefined, so by David's principle the set is ill-posed until it is written down. **Where it breaks.** Under free fall a closed curve in $V$ is a curvelet that returns to the same oriented germ (up to the #324 gauge, i.e. a germ isometry carrying $u$ to $u$). Determinism (Prop 3.2/Thm 3) makes the whole orbit periodic and the consistency condition automatically satisfied by exactly one history, so there is nothing to choose between. EKT's multiplicity comes from the loop feeding back into data that the local law does not fix (the ball's later self hits its earlier self); a state in $V$ already carries its whole analytic patch, so there is no free data to feed back. Multiplicity therefore needs non-deterministic motion first (type ii, or Set 2), and then the consistency condition is a constraint on $R$, i.e. the law of $R$ again (batch-01 T2 risk confirmed). Self-loops $(O^u,O^u)$ are noted in v0.10.1 §11 (not edited here). **Gains.** No CTC in spacetime, and counting consistent solutions would not weight them; but as stated it gives one solution, not a few. Not flagged.
