# Observer space framework (public paper)

This folder holds the **public-facing** framework paper intended for the wider physics community.

It is deliberately **not** under `papers/`, which is crowded with in-house notes (lock leftovers, kill-passes, internal theorems). Those remain internal. This paper is the readable cut of the ontology and launching pad.

## Layout

| Path | Role |
|---|---|
| `versions/` | Numbered drafts (`v0.1-outline.md`, …, `v0.3-outline.md`, `v0.3-prose.md`, …) |
| `reviews/` | External and in-house reviews; each file **must** name the version it reviews |

Living working definitions stay in the repo-root file [`mathematical-framework.md`](../../mathematical-framework.md). Update that file as we think; promote into a new `versions/` draft when ready for review. Where that file disagrees with a numbered draft, the draft wins for review purposes.
