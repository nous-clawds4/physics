## For David (one page)

**The idea.** The observer's diary is not abstract memory. It is a small set of handles in spacetime (geon-like features) that travel next to the observer but are not part of it. They exist from the start. They are not the time-loop geon the beacon probes: that geon forms later, so there is a slice S before it, and writes lie beyond the observer's Cauchy horizon H+(S) (#364 d, #381). Recording never creates or destroys a handle.

**The signal.** The observer sends out a small physical pulse of matter, not a light ray. It goes into the particle's time-loop region and comes back. This is the beacon round trip, "backscattering". It has to be matter that can interact. A light ray comes back only one way, while an interacting pulse can come back in several self-consistent ways (#379 Set 1). That is where the menu of possible replies comes from.

**Writing.** When the returning pulse reaches the diary, it changes the diary without changing its topology:
- it can push a diary body through one of the handles, which changes a signed whole-number count of passages (mouth A +1, mouth B −1, a graze 0), read as the difference from a declared reference history with the same endpoints; it has no absolute value (#385 Set 1, #387);
- if it carries charge, the electric flux through a Gauss surface around exactly one mouth changes by ±q per signed passage, and every charge that crosses counts, not just the carrier; it is a whole number only as a difference from the reference and only with a single charge species (#385 Set 3, #387; flux conserved and unquantized, Misner–Wheeler 1957, per #386). Caveat: a handle that is not orientable, or not time-orientable, as in Hadley-type geons, can carry net charge of its own and a carrier returns reading −q (Sorkin 1977; Diemer–Hadley 1999, per #386), so there the flux is not a pure count of passages.

Only replies that come back "the right way round" in time (Type O) can write. A Type F return arrives pointing backwards in time and cannot (#381). So a ℤ/2 geon whose only loop reverses time cannot write at all (#364 b, #381). Writing by creating new handles is set aside: with ordinary matter, Einstein's equations forbid it outright (Tipler 1977; Borde 1994, for causally compact regions), and only time loops or non-time-orientability let it happen at all (Geroch 1967) (#379 Set 2, #380).

**Where it sits.**
- *Relative to the observer:* the diary is part of the observer's state. The state is "germ + record" (L29), and the diary is the record, made physical. So the observer becomes a small tube (observer plus diary), whose size the diary's physics sets (#382, L52).
- *Relative to the horizon:* replies arrive beyond the observer's Cauchy horizon, where the past no longer fixes the future (#372 §2.4, #381). So the diary is written exactly where the worlds can differ. The diary tube must cross that horizon together with the observer (#382, L53).

**How it fits #372.** Under the analytic lock, the observer's *motion* is the same in every world that continues it. What differs is what it receives (#372 R2). The ledger is where that difference is physically stored. Two worlds that agree on the observer's motion but wrote different diary entries lie in two branches. A branch is the record class among the worlds in which the observer reaches τ; many worlds share one branch, and branches are nested, not crossing. The record branch is the diary state. The observer's worldline germ does not fork; the germ of the observer-plus-ledger tube does differ after a write, by construction.

**The question for you (8:13 PM):** is this notion of a ledger worth pursuing? Persistence is set aside below as a separate step.
