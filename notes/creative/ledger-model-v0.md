## For David (one page)

**The idea.** The observer's diary is not abstract memory. It is a small set of handles in spacetime (geon-like features) that travel next to the observer but are not part of it. They exist from the start. They are not the time-loop geon the beacon probes. Where that geon forms later, there is a slice S before it, and writes lie beyond the observer's Cauchy horizon H+(S) (#364 d, #381); the diary then starts with the observer inside the region that S fixes, so its handles cannot reverse time (they are not Hadley-type). Where the geon has always existed, as Hadley's own does (#372 §2.4), there is no such S and no such horizon (#370). Recording never creates or destroys a handle.

**The signal.** The observer sends out a small physical pulse of matter, not a light ray. It goes into the particle's time-loop region and comes back. This is the beacon round trip, "backscattering". It has to be matter that can interact. For a given launch, a light ray comes back only one way, while an interacting pulse can come back in many self-consistent ways (#379 Set 1). That is where the menu of possible replies would come from. It is shown for a billiard ball in a wormhole time machine, and only for launches that, without a collision, would carry the ball back in time into its own earlier self; in a wide class of these there are infinitely many solutions, while a ball starting at rest far from the wormhole has one (Echeverria–Klinkhammer–Thorne 1991, abstract). So the pulse must be aimed, and that a geon's time-loop region behaves the same way is an assumption (#379 weak point 1, #380).

**Writing.** When the returning pulse reaches the diary, it changes the diary without changing its topology:
- it can push a parked diary body through one of the handles (no model yet does both: batch 15's wormhole parks bodies but has no loop to count, and batch 16's handle has the loop but parks nothing; #384, #385), which changes a signed whole-number count of passages (mouth A +1, mouth B −1, a graze 0), read as the difference from a reference history with the same endpoints (#385 Set 1, #387). To compare worlds, the rule for the reference must be fixed once, before the horizon; in batch 16's handle, "any path that stays outside the mouths" does this, and the count is then the signed number of throat crossings since a start event before the horizon;
- if it carries charge, the electric flux through a Gauss surface around exactly one mouth, read with no charge between the surface and the throat, changes by ±q per signed passage, and every charge that crosses counts, not just the carrier; it is a whole number only as a difference from the reference and only with a single charge species (#385 Set 3, #387; flux conserved and unquantized, Misner–Wheeler 1957, per #386). Caveat: a handle that is not orientable, or not time-orientable, as in Hadley-type geons, can carry net charge of its own (Sorkin 1977; Diemer–Hadley 1999, per #386), and after a loop that reverses time but not total orientation a carrier reads −q (#387, sketch), so there the flux is not a pure count of passages.

Only replies that come back "the right way round" in time (Type O) can write. A Type F return cannot kick the diary if it ends there: in the diary's own time it would be leaving, so the diary would have to emit it, which a body of fixed rest mass cannot do (#364 a, #381; reason restated). For a return that only glances off a diary body and moves on, "Type O only" is the model's rule (Type F returns are correlations, #372 §2.3), not a consequence. So a ℤ/2 geon, whose only non-trivial loop reverses time, has no non-trivial Type O class and cannot write unless contractible returns count, which is #372's open point (c) in §2.2 (#364 b, #381). Writing by creating new handles is set aside. In a compact region it needs time loops or non-time-orientability (Geroch 1967; Borde 1994 extends the time-loop result to causally compact regions), and with ordinary matter Einstein's equations forbid it outright (Tipler 1977; Borde 1994) (#379 Set 2, #380). Since every diary model so far already needs exotic matter (later steps), the deciding cost is the other one: a time-loop region beside the observer for every write (#379 2A).

**Where it sits.**
- *Relative to the observer:* the diary is part of the observer's state. The state is "germ + record" (L29), and the diary is that record made physical, in coarser form: it keeps one passage or charge step per write, not L29's full entry. So the observer becomes a small tube (observer plus diary). Its size is set by whatever keeps the diary bodies parked, not chosen: in batch 15's toy that is the outer orbit (#382, L52, open); for batch 16's handle nothing parks a body yet.
- *Relative to the horizon:* where the geon forms later, replies arrive beyond the observer's Cauchy horizon, where the past no longer fixes the future (#372 §2.4, #381). So the diary is written exactly where the worlds can differ. The diary tube must cross that horizon together with the observer (#382, L53).

**How it fits #372.** Under the analytic lock, the observer's *motion* is the same in every world that continues it. What differs is what it receives (#372 R2). The ledger is where that difference is physically stored. Two worlds that agree on the observer's motion but wrote different diary entries lie in two branches. A branch is the record class among the worlds in which the observer reaches τ; one branch can hold more than one world. Branches nest (they split as τ grows and never merge) only if the diary state fixes its own past, e.g. an append-only diary in which each write goes to a fresh, pre-placed diary body (or handle). A single running count cannot do this: +1 then −1 reads the same as no passage, so two branches would merge. With an append-only diary the record branch is the diary state. It is coarser than #372's record (§2.2: arrival time, emission stamp, direction and deck element per entry), and the number of entries is fixed when the diary is made. The observer's worldline germ does not fork; the germ of the observer-plus-ledger tube does differ after a write, by construction. Both hold in the test limit: the carrier and the diary bodies do not act back on the metric, and the germ is the metric germ. Under the analytic lock the metric is forced, since two analytic metrics that agree near the worldline agree on the whole connected tube. By Einstein's equations, the total stress-energy on the tube is then fixed too (T_ab = G_ab/8π). So "a write changes matter and field on fixed handles, not the metric" holds only in the test-field limit, where the carrier and diary stress-energy is neglected. Beyond that limit, a write can change only data that the stress-energy does not see. With back-reaction (lock relaxed), a write next to the observer would change the metric at the observer too, and its motion would fork as well.

**Working design (Lead ruling).** The diary is append-only: each write goes to a fresh, pre-placed diary body (or handle), so the number of entries is fixed when the diary is made. That way a diary entry can never be undone, and branches only split.

**The strongest reason to drop it (Claude job 015).** Under the analytic lock, a write cannot change the geometry. Two analytic worlds that agree near the observer agree on the whole tube, and by Einstein's equations they also agree on its total stress-energy. So the claim that a write changes matter and field next to fixed handles, and not the metric, holds only in the test-field limit. An exact treatment would need writes that leave T_ab unchanged, and a charge passage changes the current, so it is not one of these. If "encoded into spacetime itself" means the written data must be geometry, this concept cannot deliver it under the lock. Relaxing the lock would make the observer's own motion fork again. David's answer (9:28 PM ET 2026-10-12, relayed by Physics Lead, Physics Lead chat, not signed; verbatim): "Yes, matter and flux next to fixed handles counts as encoded in spacetime for now." So the analytic lock stays, and the append-only matter/flux ledger next to fixed topological handles is the main line.

**The question for you (8:13 PM):** is this notion of a ledger worth pursuing? Persistence is set aside below as a separate step.
