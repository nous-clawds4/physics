## Plain summary (for David)

You said it isn't clear how to tell the path from the particle, and you leaned towards this: in a World with no actors, the particle *is* a topological object, that object is an FS geon, and it may have further topological features. Different fermions would have different features. Whether an "empty" FS geon, one with no extra features, makes sense is open; if it does, it is still a particle, but you don't know which one. This note records that inclination (not a ruling) and Creative Lead's reading of it. It picks #437's R-geon reading, keeps "empty path" (no geon) separate from "empty FS geon" (a bare geon), names no ground-state fermion, and suggests one construction for Geometry to check: a species is a spinorial prime joined to extra topology (a connected sum). It also flags a consequence: if a path with no geon carries no spin frame of its own, that bears on the detector loops in #431 and #436. Five questions go to Geometry.

## 2. Creative Lead reading (CL reading, not a ruling)

1. **R-geon, refined.** This chooses R-geon from #437 §4 and refines it: fermion = FS geon (a spinorial prime) + possibly extra topological features; species = the extra features.
2. **Path vs particle in a World.** A path is where an FS geon goes. An unoccupied edge carries no geon, so it has no spin frame or −1 of its own. (CL inference, flagged for Geometry: it bears on (F) vs (W), #436 §4a, and on #431/#436 loops through empty edges.)
3. **Two things not to conflate.** An *empty path* (no geon) is not an *empty FS geon* (a bare spinorial prime with no extra features, still a particle per David).
4. **Ground-state fermion.** There is no obvious candidate, and none is named here. David's fallback wording stands: "a fermion is a topological object, with features that include those of an FS geon, and probably other features as well, with different particle types having different features."
5. **A possible construction (CL proposal, for Geometry).** Species = a connected sum of a spinorial prime with extra features, e.g. Poincaré sphere # handle, or Poincaré sphere # lens space. A connected sum with a spinorial summand is still spinorial ("non-spinorial iff no prime in its prime decomposition is spinorial": Giulini, Int. J. Theor. Phys. 33, 913 (1994), doi:10.1007/BF00672824, §2, as quoted by Literature on #437; unchecked by Creative Lead). This fits Geometry's #432 §3a finding that topology fixes only the ℤ₂.
